# 大学生健身台

一个给大学生用的个人健身工作台：把**课表**、**训练计划轮换**、**身体数据**放进一张两个月日历里，自动算出"哪天有空、哪天练什么"。

🔗 在线地址：https://fitness-dashboard-orcin-alpha.vercel.app/

## 功能

- **首页**：今天要处理（逾期标红、一键补完成）、今日训练部位 + 动作清单 + 一键打卡、今日课程与空闲时段推荐
- **日历**：课程与训练合并显示，格子里直接看到课程首字、上课时间、地点，以及当天练哪个部位
- **训练计划**：二 / 三 / 四 / 五分化模板，选好部位和动作后按「练 N 天 + 自动休 1 天」循环铺满日历；手动点「这天休息」可整体顺延
- **课程管理**：支持单双周（每周 / 单周 / 双周），自动按自然周奇偶过滤
- **身体数据**：体重趋势图、睡眠、腰围记录，内置 BMI 与体脂率计算器

## 技术

- 单文件 HTML，CSS / JS / 图标全部内联，零外部依赖，离线可用
- 数据存云端数据表，手机电脑自动同步；断网自动降级为本地存储
- 图表用手写内联 SVG，没有引任何图表库
